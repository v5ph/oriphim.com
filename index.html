How it works

Nothing runs until you sign off.

  1. Bring itYour model, notes, code, or a paper you're building on.
  2. RebuildEquations and parameters, each tied to where it came from.
  3. Sign offYou approve the plan before anything runs.
  4. Run and checkConvergence, conservation, and sensitivity to every free parameter.

Any starting point

Gaps in your notes don't stop the run.

Stated

Every equation and value you give, tied to where it came from.

Inferred

Grids, seeds and settings you left out, filled from the field's practice and marked in the plan.

Stand-in

No dataset? A seeded one with the same shape, so the experiment still runs.

Fills are never tuned toward the answer you hope for, and the Evidence Pack says which results rest on them.

Discovery

Ask the next question.

Change an assumption, sweep a parameter, try another method. Every run is checked the same way, so what you find next stands on the same ground as what you started with.
