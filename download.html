Before you install

Requirements.

Mac

  • Apple Silicon (M1 or later); Intel Macs are not supported
  • macOS 14 Sonoma or later
  • 8 GB memory, 16 GB recommended
  • About 2 GB free disk space per installed version

Terminal

  • Terminal, iTerm2, Ghostty, WezTerm or any modern terminal
  • Keyboard and mouse supported; ori --accessible gives plain line-by-line text for screen readers
  • Dark, light, 16-colour and colour-blind-friendly themes: /theme

Network & account

  • A Standard subscription to start new work
  • Internet for sign-in, the hosted model and updates
  • Experiments run on your Mac; up to seven days offline between subscription checks
  • Results stay readable and exportable if your subscription ends

Optional

Use a local model or your own endpoint.

Ori can interpret with a model on your Mac or any OpenAI-compatible endpoint instead of Oriphim’s hosted model. These use no cloud credits and keep working when the month’s credits are used. Ori never bundles model weights: download a model with your runtime first. A Standard subscription is still required.

# a local runtime such as Ollama, already serving a model
/model local http://127.0.0.1:11434/v1 your-model-name

# your own provider and key (the key is stored in the macOS Keychain)
ori model byok https://api.example.com/v1 model-name

# back to Oriphim's hosted model
/model hosted

If something goes wrong

Troubleshooting.

zsh: command not found: ori

~/.local/bin is not on your PATH yet. The installer prints the exact line for your shell; for zsh it is:

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
“Ori needs an Apple Silicon Mac”

Ori is built for Apple Silicon only. A Terminal running under Rosetta on an Apple Silicon Mac is detected and handled; Intel Macs are not supported.

“integrity check failed” or a download error

Nothing was installed or changed. Run the command again. Behind a proxy, set HTTPS_PROXY before running it. If it keeps failing, report it with the output.

“exists and is not a link Ori made”

Something else is installed at ~/.local/bin/ori. Ori will not overwrite it; move it aside and run the installer again.

An update caused a problem

ori rollback switches back to the previous version, which is kept. ori update --pin VERSION stays on one version. Running experiments always finish on the version they started with.

Signed in, but Ori says the subscription is not active

After Checkout, access starts when Stripe confirms the payment, usually within a minute. /billing shows the confirmed state. Payment problems and renewal dates are shown there and on your account page.

Reporting a problem

Run ori doctor --json > ori-doctor.json and send it through the contact page with what you did and what you saw. It describes your installation and dependencies, not your research. Ori sends no usage or research telemetry; diagnostics leave your Mac only when you send them.
